# Q-GANG

Q-GANG is being rebuilt from zero as a gaming community platform.

## Alpha 0.1 thesis

**Play · Create · Connect**

The first product loop is:

1. Sign in with Google, Discord or Steam.
2. Create one Q-GANG identity.
3. Join a game Campfire.
4. Discover people around the same game.
5. Post, react and comment.
6. Use **Play Together** to move the connection toward Steam/Discord and the actual game.

## Stack

- Next.js
- TypeScript
- Supabase (PostgreSQL, Auth, Storage, Realtime)
- GitHub
- Deployment target to be wired after the foundation build passes.
